# Flutre

A short composition for Acoustic Grand Piano and Flute.

## About
Flutre is an original composition inspired by:
- Sudden gusts of wind while sitting on the field

The piece follows a wave-like structure:
Opening (rustling) → Build-up → Dust tornado (peak) → 
Descent → Resolution

**Tempo:** 120 BPM
**Time Signature:** 4/4
**Duration:** ~36 seconds
**Instrumentation:** Accoustic Grand Piano + Flute

## Composition Journey
Created using Crescendo notation software, entirely by ear 
without formal music theory training. Uses intuitive 
orchestration and rhythm variation to convey emotional arc.
